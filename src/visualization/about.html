O projekcie

Cel projektu

Celem projektu jest zaprojektowanie oraz implementacja systemu predykcji natężenia ruchu drogowego w kontekście koncepcji Smart City. Projekt wykorzystuje metody uczenia maszynowego do analizy danych historycznych i prognozowania przyszłych wartości ruchu.

Zakres projektu

  • Analiza danych ruchu drogowego
  • Przygotowanie danych sekwencyjnych
  • Implementacja modelu LSTM
  • Trening i ewaluacja modelu
  • Wizualizacja wyników predykcji

Wykorzystane technologie

W ramach realizacji projektu wykorzystano zestaw narzędzi i technologii umożliwiających pozyskiwanie danych, ich przetwarzanie, trenowanie modelu predykcyjnego oraz prezentację wyników.

Warstwa analityczna i uczenie maszynowe:

  • Python – główny język programowania wykorzystywany do analizy danych i implementacji modelu,
  • PyTorch – biblioteka do budowy i trenowania rekurencyjnych sieci neuronowych (LSTM),
  • NumPy oraz pandas – przetwarzanie, czyszczenie i analiza danych,
  • scikit-learn – podział danych, walidacja oraz obliczanie metryk jakości modelu.

Pozyskiwanie i przygotowanie danych:

  • API Transport for London (TfL) – źródło publicznych danych o natężeniu ruchu miejskiego,
  • CSV – format przechowywania danych wejściowych i pośrednich.

Wizualizacja i prezentacja wyników:

  • matplotlib – wizualizacja danych wejściowych oraz wyników predykcji,
  • HTML i CSS – stworzenie strony internetowej prezentującej założenia i rezultaty projektu.

Narzędzia wspomagające:

  • Git / GitHub – kontrola wersji oraz współpraca zespołowa,
  • Visual Studio Code – środowisko programistyczne wykorzystane podczas realizacji projektu.

Zastosowany zestaw technologii umożliwił stworzenie spójnego prototypu systemu prognozowania natężenia ruchu miejskiego w kontekście koncepcji smart city.

Podsumowanie

Projekt demonstruje możliwość wykorzystania rekurencyjnych sieci neuronowych do analizy danych czasowych w zastosowaniach miejskich. Uzyskane wyniki potwierdzają zasadność użycia modelu LSTM w problemach predykcji ruchu drogowego.
